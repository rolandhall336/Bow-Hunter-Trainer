Bow Hunter Trainer

This is an installable web app (PWA) for iPhone.

Features:
- Monday, Tuesday, Thursday, and Saturday workouts
- Weight/set logging and completion tracking
- Weekly progress check-ins
- Notes and streak tracking
- Export/import backup
- Offline use after installation

To install on iPhone:
1. Put this folder on a static HTTPS host such as GitHub Pages, Netlify, or Cloudflare Pages.
2. Open the site in Safari.
3. Share > Add to Home Screen.

Your workout data stays in your browser/device. Use Export Backup occasionally.
